# Day 1

## 오늘의 목표

AWS 기반 정적 웹사이트 호스팅 포트폴리오 프로젝트의 기본 구조를 만든다.

## 오늘 한 일

- GitHub 저장소 생성
- 프로젝트 폴더 구조 생성
- README.md 초안 작성
- 아키텍처 초안 작성
- 기본 index.html 파일 생성

## SAA 복습 연결

- S3: 정적 웹사이트 호스팅 가능
- CloudFront: CDN, 캐싱, HTTPS, 엣지 로케이션
- Route 53: DNS 서비스
- ACM: SSL/TLS 인증서 관리
- IAM: 최소 권한 원칙 적용 필요

## 완료한 작업

- 프로젝트 디렉토리 구조 생성
- README.md 작성
- 로컬 Git 저장소와 GitHub 원격 저장소 연결
- Git add, commit, push 흐름 실습
- README.md 마크다운 표시 문제 수정

## 내일 할 일

- S3 버킷 생성
- 정적 웹사이트 호스팅 설정
- index.html 업로드
- S3 퍼블릭 접근 정책 또는 CloudFront 접근 방식 검토
